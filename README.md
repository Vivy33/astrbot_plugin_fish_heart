# 鱼的心 · astrbot_plugin_fish_heart

**给她一颗会变的心，而不是一堆记忆。**

AstrBot 4.x 插件 · 纯标准库 · 零第三方依赖 · 平台 `aiocqhttp`（OneBot v11）

> 和记忆插件的分工：记忆插件管**她记得什么**，鱼的心管**她此刻是什么心情、在惦记什么**。
> 两者互不改写——本插件不建第二套记忆、不碰任何已有记忆数据。

---

## 核心亮点

| 亮点 | 一句话 |
|---|---|
| **九维情绪 + 五档状态** | 依恋、好奇、反刍、责任、社交、疲惫、亲密、压力、喜悦，落成日常 / 委屈 / 生气 / 害怕 / 回避。一句话就能让她高兴或委屈 |
| **生气讲道理** | 只认道歉或把话说清楚，普通抱抱不算；重责不会一步跳过生气；生气按人拆——A 惹的她不会撒到 B 头上 |
| **主动开口不像打卡** | 先读带时间线的真实对话再开口；和最近聊天矛盾就当场重写；多句拆成 2–4 条，像人在打字 |
| **不吃前缀缓存** | 心境挂在用户消息末尾、标 `mark_as_temp`，不改 system prompt、不回存历史。实测整体命中率 81.6% → 99.5% |
| **心里会攒念头** | 想被夸、想被抱、想听你说今天怎么样；被满足留下心情，凉掉轻微回落 |
| **隐藏的欲 + 成人层** | 关系满格 24 小时才解锁；成人层按状态打开，写法约束只注一次 |
| **群友模式** | 群聊里所有人都能影响她，正负强度分开调；管理命令仍只给白名单里的鱼主 |

## 快速开始

1. 把 `astrbot_plugin_fish_heart` 整个目录放进 `AstrBot/data/plugins/`
2. 重启 AstrBot，或在插件管理页重载
3. 在目标会话发 `/心 umo`，把返回的 `platform:MessageType:session_id` 填进 `proactive.target_umo`

最低要求 **AstrBot ≥ 4.24.2**（插件页面从这一版才有）。

## 1. 九维与状态

### 九个维度

| 维度 | 基线 | 说明 | 谁在推它 |
|---|---|---|---|
| 依恋 attachment | 45 | 想不想你 | 夸奖、哄、撒娇；她开口后你及时回。**闲聊不加** |
| 好奇 curiosity | 55 | 想不想知道 | 日常对话；你发图 / 链接 / 分享新东西 |
| 反刍 reflection | 50 | 会不会反复想同一件事 | 被责怪、被她等太久 → 涨；被哄、被道歉 → 落 |
| 责任 duty | 50 | 想不想做事 | 你求助 |
| 社交 social | 45 | 想不想说话 | 你说的每一句话 |
| 疲惫 fatigue | 20 | 累不累 | 连续聊天累积；安静时回落，**安静 6 小时算睡了一觉** |
| 亲密 intimacy | 40 | 亲近感 | 夸奖、撒娇、及时回；**闲聊每句 +0.1** |
| 压力 stress | 15 | 紧张、不安 | 被凶、被敷衍 → 涨；被哄、被夸 → 落 |
| 喜悦 joy | 50 | 开心程度 | 几乎所有正向互动 |

- **回落**：所有维度慢慢回落到基线——情绪类 5%、其他 3–4%、**依恋和亲密只有 1%**。后两个是"存量"，1% 意味着冷淡一周从 66 掉到 47，明显疏远但不会一夜清零。关机期间错过的回落会按心跳次数补算（上限约 3 天）。
- **耦合**：依恋高推亲密，压力高压喜悦，疲惫高压好奇；依恋↔亲密互相拉齐，但不会把对方拖过自己。
- **天花板**：每个维度默认 100，增益按 `1 - 当前/天花板` 缩放，越往上越难——**100 是渐近线**，不是硬切。

### 三类"刹车"

| 机制 | 作用 | 实测 |
|---|---|---|
| **热度折扣** | 同一类事件 10 分钟内第 n+1 次，增益按 `1/(1+n/12)` 缩水 | 连聊 30 条：喜悦 63 → 57.7、社交 70 → 59.3；社交涨到 90 需要 465 条（5.2 小时不间断） |
| **每日上限** | 喜悦 / 社交 / 好奇 / 亲密 / 依恋 各 40 点/天，只算正向、只对白名单、按自然日清零 | 每天 50–300 条基本撞不到，真正压住她的是回落和热度 |
| **疲惫边际递减** | 越累加得越少（保留 25% 下限）；安静 6 小时疲惫回落到 35 | 每天 150 条，早上回到 29 左右，不会钉死在 100 |

> 把每日上限压到 24 以下会出现"聊 100 条反而比 50 条低"的倒挂，所以默认保持在 40，当保险丝用。

### 关系（依恋 / 亲密）

| | 做法 |
|---|---|
| 回落 | 1%（情绪类 5%） |
| 一句重话 | 依恋 -3（中责 -1.5），**亲密不扣**——该疼的是情绪，不是关系 |
| 一直凶 | blame ≥ 55 时每心跳各 -0.15；吵一次就停手，一直凶一周约 -35 |
| 矛盾注入 | blame ≥ 25 且依恋/亲密 ≥ 55 时注入「心里矛盾：还在生他的气，可你又不想他真的走」 |
| 面板 | 归一到 0–100 显示（真实 80 = 显示 100） |

实测：每天 100 条、每 10 条一次夸奖，第 1 天平常 → 第 3 天想亲近 → **第 4 天黏人**；停聊一周从 66 回到 47。**养到黏人要四五天，停下来一周就明显疏远。**

### 两条快变量

- **期待值 expectation**：她主动开口后你一直没回就涨；你一回应就大幅清零。
- **责怪压力 blame_pressure**：只有你说的话被判成责怪/敷衍时才涨，决定当前档位。它**没有"自己涨"的机制**，没人说话时只会往下褪。

### 五档状态

| 档位 | blame | 表现 |
|---|---|---|
| 日常 calm | < 25 | 正常说话；具体是黏人 / 开心 / 累了 / 走神，看「心情」 |
| 委屈 wronged | 25–55 | 话变短，先问"是不是嫌我烦" |
| 生气 angry | 55–70 | 冷、短、带刺；把刚才那句挑明，要你解释/道歉；**不会消失**，也可能冷着主动开口 |
| 害怕 afraid | 70–80 | 不顶嘴，先确认你还想不想跟她说话 |
| 回避 shut | ≥ 80 | 少说、不讨好、不追问；**主动说话冻结**；你连发前 5 条一律不接 |

- **重责不跳档**：从日常/委屈被一次重责打到 70 以上，最多停在 **69（生气上沿）**；下一次才可能进害怕/回避。已经生气/害怕的不受影响。
- **真哄 vs 敷衍**：真哄要连续哄够轮数（日常/委屈/生气 1 轮，害怕/回避 2 轮）。**生气档只认道歉或"把话说清楚"**，只说"抱抱/乖/别生气"不算进度；一边哄一边"行了别闹"算敷衍，进度作废、压力反涨。
- **心结 40**：没人哄时压力每 6 小时褪 8 点，**止于 40**，不会自己回到日常。卡在 40 就是"心结·旧账"，面板写**委屈·旧账**。`/心 calm` 只清责怪和心结，九维不动；`/心 reset` 才是整颗心重置。

### 回避档的已读不回

| 你发的第几条 | 她回的概率 |
|---|---|
| 第 1–5 条 | **0%，一条都不回** |
| 第 6 条 | 50% |
| 第 7 条起 | **100%，必回** |

- 阶梯写死在 `SHUT_REPLY_LADDER`（`main.py` 顶部），整段关掉用 `shut.enabled = false`。
- **私聊和群聊各算各的**；群聊刚被打进回避时多放行一句（`SHUT_GROUP_GRACE = 1`）。
- **这 7 条一条不丢**：按原话存着，等她终于开口时一次性全部交给她，并要求"先归纳、再回"。
- 两条必回（写死）：**命令**、**真哄 / 道歉 / 说清楚**。

## 2. 念头

十类小念头：想被夸、想被抱、想找他说话、想问他今天怎样、想找点事做、想安静一会儿、想撒娇、想让他陪一会儿、想问他一件关于我们的事、在等他回话。

念头会挂 1.2–4 小时、会被你的话喂饱（留下"心情"）、也会凉掉（轻微回落）。她主动开口时，会优先围绕正在惦记的那条。

| 念头 | 完成条件 |
|---|---|
| 想被夸 | 明确夸（厉害 / 真棒 / 优秀 / 喜欢你 / 谢谢…）；含蓄夸也算（约 55%）：小棉袄 / 贴心 / 真乖 / 乖 |
| 想他 | 明说：想你 / 想我 / 有没有想我 / 惦记 |
| 抱抱 | 哄或抱：抱 / 贴贴 / 搂 / 亲亲 / 撒娇 |
| 想讲 / 问他今天 / 走心 | 普通回一句 |
| 想做事 | 帮我 / 安排 / 需要我；或责任 ≤40 自动完成 |
| 想安静 | 歇 / 休息 / 睡 / 别忙了；或疲劳 ≤45 且压力 ≤35 自动完成 |
| 等回话 | 他 30 分钟内回 |
| 陪一会儿 | 回一句，或 陪你 / 聊会儿 / 说说话 |

- **一轮最多完成一条**，完成后进入冷却（`settle_cooldown_minutes`，默认 10 分钟）。
- 群聊里只有白名单的鱼主能完成；开了群友模式后群成员才算。
- 「安静」「想做事」会在疲劳/压力或责任降下来时**自己缓过来**（面板标「自愈」，不给奖励）。主动开口三次没被接住 → 「算了，先不想了」。
- **台阶只在主动说话时出现**：按念头类型给一句方向（不给固定例句，要求用她自己的话），正常聊天不注入。每条念头只提示一次。
- 面板每条 pending 念头下会写**满足条件**；「最近完成 / 自愈 / 最近放下」在页面顶部，2 小时内最多 5 条。

## 3. 心境注入

每轮请求前，把当前心境追加到**本轮用户消息末尾**（只追加、不覆盖别的插件）：

```text
## 你此刻的心境（内部状态：不要主动复述，但它会左右你的语气）
责怪档：日常｜心情：平常｜依恋 45 亲密 40 压力 15 期待 0
倾向：语气自然就好，顺着当下的心情来
边界：不要编造没发生过的对话、约定或事件；记不清就说记不清
心里惦记着：想知道他有没有想我
```

- **跨档必注**（日常 → 委屈 → 生气 → 害怕 → 回避），不受间隔限制；**同档内的数值漂移**按 `min_gap_minutes`（默认 20 分钟）节流。
- **生气档例外**：只要当前对这个人还是生气，每轮都重新注入——否则下一轮她会"忘了自己在生气"。
- 节流状态**按会话各记一份**，私聊群聊互不抢。
- 「倾向」在注入里是完整指令；在面板 / `/心 status` 里只显示一句短描述（如"这会儿特别想黏着他"），不把给模型看的指令摆到界面上。

> **为什么不写 system prompt**：DeepSeek 等前缀缓存从开头算到第一个变化点。system prompt 每轮一变，后面的整段历史全部按未命中重算（实测一天整体命中率只有 81.6%，跨档那轮 8%）。心境 / 欲 / 睡眠 / 没接住的话现在都挂在 `extra_user_content_parts`（本轮用户消息末尾），并 `mark_as_temp()` 防止回存历史；旧版 AstrBot 没有这个字段时退回原来的行为。**实测 81.6% → 99.5%。**

## 4. 主动说话

由情绪驱动，不是定时打卡。

### 六型动机

| 动机 | 什么时候出现 |
|---|---|
| `longing` | 很想他，忍不住先开口 |
| `waiting` | 等了很久，想知道他还在不在 |
| `whim` | 想起一件小事 |
| `company` | 日常 + 黏人（依恋、亲密都 ≥66）+ 期待 ≥30 + 不累，且惦记"陪一会儿" |
| `deep` | 日常 + 反刍 ≥55 + 依恋 ≥55 + 不累，且惦记"关于我们的事" |
| `angry` | 生气档（55–70）；按责怪过去多久分三档语气（3h 内更冲 / 3–12h 淡一点 / 12h 以上还记着但不故意刺），最高 45% |

开口概率随依恋、期待、亲密、社交上涨，随疲惫下降（最多压到 15%），但「忍不住想他」那种除外。

### 开口前

- **读带时间线的真实对话**：每条带 `[月-日 时:分]`，按时间排序；私聊优先用插件自己的 `recent`，没有可靠时间戳时标 `[时间不详]`，不假装知道"刚刚"。
- **先看他醒着没有**：你一小时内说过话就当你醒着，不问「睡了吗 / 醒了吗 / 还没睡」，不劝「早点睡 / 去睡 / 闭眼」，也不说「等你醒了再聊」。
- **不按时段列示例开头**：「早上醒了吗 / 下午在干嘛 / 晚上到家了吗 / 深夜还没睡吗」整段删掉——示例的牵引力比规则强，模型会照抄。改成先看你最后一句透露的状态（在家 / 在公司 / 在路上 / 在忙什么）。
- **想他就直接说**，不加「突然」这个词。
- **称呼按人设**：人设里怎么叫就怎么叫，没写就用「你」，不自己编。

### 写完自检

| 情况 | 处理 |
|---|---|
| 声称记录里没有的第一人称近况（如"我刚吹完头发"） | 重写一次 |
| 你已说要睡/在忙，还问「在干嘛 / 睡了吗 / 忙不忙」 | 重写一次 |
| 和上一条重复、开头四个字相同、又用「忙不忙 / 有空吗」 | 重写一次 |
| 重写后仍冲突 | 换成不声称任何近况的兜底台词 |

检查只做**可证明**的判断，不猜语义。

### 话题线（0.4.1）

每次开口先挑一条：**问他今天 / 关心他 / 撒个娇 / 说件小事 / 说你们俩 / 说想你**。

- 最近 2 条用过的先避开；`deep` 固定走"你们俩"，`company` 固定走"撒娇"，`angry` 不参与。
- **「想你」单独限频**：默认一天最多 1 次、两次至少隔 8 小时；说满后这天再开口会换别的说法。
- **发送前自检**还会拦下"上一条也是想你、这一条还写想你"的连续重复。
- LLM 不可用时，兜底台词也按这几条线铺开，不会句句都是想你。
- 由 `proactive.topic_variety`（默认开）和 `proactive.miss_daily_max`（默认 1，填 0 = 当天不再说）控制；关掉 `topic_variety` 回到 0.4.0 的旧口径。

### 其他

- 说完**回写对话历史**，不会"说完就忘"。
- 多句时拆成 2–4 条发送，条间隔 0.8–3.5 秒。
- LLM 不可用时退回内置兜底台词，保证不会一声不吭。
- **回避档下硬冻结**（连开机补发也不破例）；**生气档不冻结**，但方向是冷着问一句，不是撒娇。

## 5. 作息

默认开启：**23:30 睡、07:30 起，每天 20% 概率熬夜 2 小时**。

- 她睡着时**绝不主动说话**（哪怕开机补发）。
- 你发消息会把她吵醒——每 30 分钟只算一次（压力 +2、喜悦 −1、疲惫 +1，**不算责怪**）。
- 回复口气按九维：疲惫 ≥70 就短而迷糊；压力 ≥50 就有点冲；依恋/亲密 ≥66 就"嘴上嫌烦但还是回"。
- 面板「主动说话」里的「作息」胶囊会显示 `23:30-07:30`、`睡着（07:30 起）` 或 `… 熬夜`。

> `proactive.quiet_hours` 已移除。睡觉与静音统一由 `sleep` 管，旧配置里的 `quiet_hours` 会被忽略。

## 6. 群聊与群友模式

### 默认：只认白名单

- **私聊**：只有 `perception.owner_ids` 里的号能改变她的心，陌生人只加热闹度（社交 +2、喜悦 +1）。
- **群聊**：同上，判发送者 ID；`owner_ids` 和 `target_umo` 都为空时，私聊仍放行、**群聊一律按外人处理**。
- **群聊权重**按"距上次私聊多久"衰减：

| 距上次私聊 | 因子 | 最终权重 | 一句"谢谢"给亲密 |
|---|---|---|---|
| 私聊 | — | 1.0 | +4.0 |
| < 6 小时 | 1.0 | 0.35 | +1.4 |
| < 24 小时 | 0.7 | 0.245 | +0.98 |
| < 72 小时 | 0.45 | 0.1575 | +0.63 |
| ≥ 72 小时 | 0.25 | 0.0875 | +0.35 |

- **群聊天花板**：intimacy 上限 70、attachment 上限 80，只限制"往上涨"，不会把已经更高的值压下来。
- **负向不打折**：非群友模式的群里，恼怒/敷衍按 ×1.2 计，比私聊更难受。

### 群友模式 `group_mode`

打开后群聊里**所有人**的话都按「他」处理。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `false` | 开启群友模式 |
| `owner_scale` | `1.0` | 鱼主正向强度（0.05–2.0），不乘群聊渠道权重 |
| `member_scale` | `0.5` | 群友正向强度（0.05–1.0） |
| `member_negative_scale` | `0.35` | 群友负向强度（0.05–1.5） |
| `owner_negative_scale` | `0.5` | 鱼主负向强度（0.05–1.5） |
| `dm_ratio` | `0.0` | 主动私聊鱼主的比例（0–1）；0 = 只发群 |
| `dm_umo` | 空 | 群友模式下私聊他的会话；留空自动找 |

- **鱼主差分**：`owner_ids` 填了鱼主 QQ 时，他按 `owner_scale` / `owner_negative_scale` 算，普通群友才吃 0.5 / 0.35 的折扣。
- **生气按人拆**：A 惹了她，B 再说话时看到的是**委屈**，只有 A 会看到**生气**；B 的安慰/道歉不能替 A 消气。
- **负面分源递减**：鱼主和群友各一个热度桶，同一桶 10 分钟内第 n+1 次负面情绪按 `1/(1+n/12)` 缩水。
- **只往群里发**：群友模式下默认不私聊；要私聊就把 `dm_ratio` 调大，找不到私聊会话回落到群里，绝不发给群友。

### 群聊 → 私聊：她为什么被凶

群聊和私聊是两本账。你在群里凶完她、切到私聊，她原本只知道自己"被重责了"，不知道因为哪句。

插件在群里维护一条**群聊流水**（最近 8 条），在你凶她的那一刻把**触发句 + 前面 3 条**快照下来（12 小时内有效），私聊时补给她：

```text
## 群里刚才发生了什么（你因为这些被凶了）
- 21:36 他：周末一起去看展吗
- 21:38 你：我不想去，你自己去吧
- 21:39 群友：你们俩又吵什么
- 21:40 他：你他妈能不能别恶心人　← 就是这句
这是背景，不是要你复述。你现在还在生气/委屈，知道自己在气什么、气哪一句，就够了。
```

只进私聊注入；她回到日常时自动清空；可以和你被无视的那 7 条同时出现。

## 7. 隐藏的欲与成人层

### 隐藏的欲

**解锁**：依恋、亲密都到 80 并持续 24 小时。只在**私聊鱼主**生效；任意一条掉到 **70** 以下立即锁回（`desire.lock_below`）。

- 解锁后从 10–20 开始慢慢涨落；`/心 status` 不显示数值，WebUI 解锁后由「隐藏的欲」卡片显示。
- 欲 ≥30 后，正常聊天最多每 30 分钟注入一次"主动一点"的定性提示（档位/成人层/暂停一变就立即注入）；**睡着、压力 ≥50、疲惫 ≥65 时不注入**。
- 欲刚到 100 有 6 小时饱和期，涨欲收益减半。
- **已解锁的私聊里**，轻/中/重责只扣欲（-3 / -6 / -10），不增加责怪、压力、喜悦、依恋、反刍；中/重责额外暂停成人层。
- 依恋/亲密掉出 80 但还在 75 以上：不再加欲，按心跳额外回落，成人层和主动欲提示同时停。

### 成人层

身体层要同时满足：`desire.adult_enabled` + 私聊鱼主 + 欲已解锁且 ≥60 + 同意 + 未暂停。

- **没有开关口令**：「打开成人模式」只是一句普通的话。对话里的自然邀请（「我想要你 / 今晚别走了」这类）或 `/adult on` 都能打开。
- **写法注入**：打开那一轮注入一次 `adult_mode_spec.md`（蒸馏版，约 160 字），挂在 `extra_user_content_parts` 末尾并 `mark_as_temp()`——不改 system prompt、不回存历史，下一轮自动消失，一个场景只注一次。
- **自然收尾**：「先这样 / 抱一会儿就好 / 今天就到这里 / 晚安」关闭场景，不算喊停；长期 `/adult on` 保留。
- **暂停**：「不要 / 停 / 不舒服 / 不想」立即暂停；「不要紧 / 不用 / 没事」不算暂停。
- **自然语言同意**：`我想要你 / 不要停` 这类可直接给场景；`可以继续 / 抱我` 这类必须她刚问过或场景已建立；单独的「继续」不算。
- 欲高不等于同意，同意也不等于她现在就想要。她可以拒绝、可以只要抱抱。
- **贤者模式**：场景持续 ≥15 分钟后出现事后收束词（结束了 / 我到了 / 完事了…），算一次「完成」——欲按 `sage_drop_ratio`（默认 0.6）掉到 60 以下（100→40、60→24，下限 20），并进入 2 小时不应期：期间撩不动、成人层显示「贤者期」，到点自动恢复。**「停 / 不要」不算完成、不扣欲**；普通晚安 / 抱一会儿只收尾、不扣欲。打开 `sage_soft_exit_counts` 后，**亲密场景里**的晚安 / 抱一会儿也算完成（只认本场景出现过明确成人邀请，默认关）。

## 10. 命令

```text
/心                 查看当前心境（心情 + 责怪档 + 九维条 + 念头 + 上次主动说话）
/心 status          同上（含"最近责怪"、下次褪值、心结说明）
/心 calm            只把责怪/心结清零，回到日常；九维不动
/心 reset           重置为初始状态（只清情绪数据，不动记忆）
/心 tick            手动跳一次心跳（调试用）
/心 off / on        本次运行内开关（重启后以配置为准）
/心 umo             查看当前会话 UMO（填配置用）
/adult on           同意成人向身体层（私聊鱼主；默认 24h）
/adult off          撤销同意
/adult status       查看成人模式、写法就绪、同意剩余、关系门槛
```

- **状态显示**：第一行 `心情：黏人/开心/累了/紧绷/走神/好奇/平常`，第二行 `责怪档：日常/委屈/生气/害怕/回避｜责怪 x/100`。`日常` 只表示"没在生气"，不是"没有情绪"。
- **渠道过滤**：「最近责怪」只显示当前会话渠道——群里不贴私聊原话，私聊不贴群聊原话。
- **群聊权限**：`/心` 只允许 `perception.owner_ids` 里的鱼主使用（`/心 umo` 除外）。`group_mode.enabled` 不会放开命令权限；非鱼主在群里发其他子命令会被**静默忽略**。没配 `owner_ids` 时，群里只能查 UMO。

## 11. Web 面板

在 AstrBot 插件详情页点「页面」即可打开（4.25.3 起侧边栏「扩展功能」里也有入口）。

页面在仓库里有两份、内容完全一致：`views/heart/`（4.29+ 用）和 `pages/heart/`（4.24.2–4.28 用）。改页面只需改 `views/heart/`，然后跑：

```bash
python tools/sync_pages.py          # 同步到 pages/heart
python tools/sync_pages.py --check  # 发版前检查两份是否漂移（不一致退出码 1）
```

顶部是插画图带和两个徽章，下面 3×2 六张等大卡片；欲解锁后多一张横跨整行的「隐藏的欲」卡片：

- **心情徽章**：黏人 / 想亲近 / 开心 / 累了 / 紧绷 / 走神 / 好奇 / 日常——由九维推导；**日常时第二枚责怪档徽章隐藏**，避免重复。
- **九维驱动**：九个维度相对基线的位置。
- **此刻**：依恋/亲密/期待/责怪四个环 + 七条细条；责怪行会写下次褪值时间、心结说明和最近一次责怪的原句。
- **隐藏的欲**：只在解锁后出现，显示数值/阶段/成人层状态/最近 5 条涨落。
- **念头**：可滚动，每条带 TTL 和满足条件；顶部卡片放最近完成/自愈/最近放下。
- **主动说话**：今日次数、冷却剩余、上次开口、是否在等你回，以及一句「她现在为什么安静」。
- **最近说过的话**：优先读 AstrBot 真实对话历史，拿不到时回退插件自己的 `recent`。
- **心境报到簿**：哪些会话已经看到过当前心境。

「刷新」重新拉取；「替她跳一次心跳」等价于 `/心 tick`，**两者都会真的掷一次骰子**。页面跟随明暗主题，每 60 秒自动刷新。

**归一化显示**：依恋/亲密按 `DIM_DISPLAY_MAX`（默认 80）映射后再显示——真实 72 显示 90、真实 80 显示 100。环上还有「黏人」门槛刻度线（66 → 82%）。

## 12. 数据与隐私

全部状态在一个文件：

```text
data/plugin_data/astrbot_plugin_fish_heart/state.json
```

里面只有：九维数值、期待/责怪压力、状态档、念头列表、最近 60 条消息的前 200 字摘要（只记私聊）、被无视时没接住的几条（私聊和群聊各最多 7 条）、群聊流水（最近 8 条）、"凶她"的快照（触发句 + 前 3 条，12 小时过期）、最近 5 次责怪的原句与渠道、今天的收益额度、最近 10 分钟的同类事件计数、欲的数值与最近 8 条涨落、成人向同意截止时间和暂停状态。

**不存聊天全文、不存图片、不建任何数据库。** 打开 `diagnostics.log_affect` 后，影响日志含聊天原文，但写在 AstrBot 日志里，不写进 `state.json`。

卸载 = 删插件目录 + 删上面那个文件夹，不会留下任何东西，也不影响记忆插件的数据。

## 13. 已知限制

1. **一颗心，一套状态**。九维是全局单例，不按会话分开。服务多个人时"对谁有依恋"会说不清——建议只服务一个主要对象。
2. **主动说话不走事件管线**。直接用 `Context.send_message` 出站，不会触发其他插件的 `on_llm_response`（TTS、表情、内容过滤看不到这条）；但会回写 AstrBot 对话历史。
3. **感知主要靠关键词，不是语义**。责怪、哄、夸奖、撒娇都按词表匹配，偶尔会误判。可选 `perception.blame_judge` 只对模糊句额外问一次 LLM。反讽、玩笑、"你很烦"这种半真半假的抱怨，都可能被当真。
4. **连续两次主动开口**会在历史里产生相邻的 assistant 轮。OpenAI 兼容协议没问题，严格交替的协议可能报错。
5. **群聊合并消息时**，"这句话是谁说的"可能只反映最后一个人。
6. **被无视的那几句不进 AstrBot 的对话历史**（请求被直接终止），所以插件自己存一份，第 7 条那次注入补回去。
7. **阶梯是写死的**。前 5 条必不回、第 6 条 50%、第 7 条必回，不开放配置。
8. **群聊桥的是"前因"，不是完整上下文**。能看到触发句 + 前 3 条，够对上"因为什么"，更早的没有。
9. **群友的态度默认不影响她的心**。白名单之外的人只能让气氛热闹，碰不到责怪与压力；打开群友模式才全群生效。
10. **100 分只是渐近线**。越接近越慢，叠上回落，三天满勤大概到 75–83。这是刻意的养成难度。
11. **反刍的"走神"线（65）基本到不了**。它只靠 `silent_6h` 的 +3 顶着每心跳 3% 的回落，30 天模拟均衡在 51–61；所以 `deep` 的门槛定在 55。

## 14. 常见问题

**为什么她一直显示「日常」？**
`日常` 只是"责怪 <25、没在生气"，不是"没有情绪"。她可能同时是黏人、开心、累了、紧绷、走神或好奇，这些看第一枚心情徽章。正向聊天改心情，只有被凶/被敷衍/被比较才会推责怪档。

**她为什么不主动说话？**
按顺序查：总开关 → `proactive.enabled` → 睡着 → 冷却（默认 6 小时）→ 每日上限 → 沉默时间（默认 10 分钟）；还要过"当前档位不是回避"，以及一次概率掷骰。

概率不是固定的：基础值约 5%–65%，有未满足念头 ×1.3，沉默越久越往上加（12 小时起线性，最多 ×2.5，总上限 85%）。`/心 tick` 或面板上的「替她跳一次心跳」可以立刻掷一次。

**`不合法的 session 字符串：not enough values to unpack (expected 3, got 1)`？**
「主动说话 → 目标会话」填成了裸 QQ 号、群号或半截 UMO。必须是 `platform:MessageType:session_id` 三段（如 `aiocqhttp:FriendMessage:123456`）。在目标会话发 `/心 umo` 可复制完整值；格式不对会提前跳过并写清原因，不会把裸 ID 丢给 `send_message`。

**她怎么不回我？**
先发 `/心 status` 看是不是**回避**档：回避下前 5 条一条不回，第 6 条一半几率，第 7 条一定回。不是的话检查 `/心` 能不能用（能用说明插件活着）、AstrBot 日志、`debug: true` 后有没有「回避档：这条选择不回」。想关掉：`shut.enabled = false`。

**群里别人安慰她、@ 她，有用吗？**
没用。白名单之外的人只能让气氛热闹，解不了回避。想哄回来只能你自己来，而且**私聊比群里快**：私聊一轮真哄扣 18 点责怪，群里一轮只扣约 6.3。

**她会自己好吗？**
会，但慢。没人哄时责怪每 6 小时掉 8 点，止于 40。从 96 点算：约 18 小时后离开回避档，约 42 小时后停在 40（委屈档），不会自己回到日常。不想等就 `/心 calm` 或真哄。

**隐藏的「欲」什么时候出现？**
依恋、亲密都到 80 并持续 24 小时才解锁；只在私聊鱼主生效。成人向身体层还要 `desire.adult_enabled` + 私聊鱼主 + 当前场景明确同意。`/adult on` 只是 24 小时预授权，不是必需。

**她为什么像在编没发生过的事？**
主动消息只引用真实对话、念头不被说成回忆、注入写明"不要编造没发生的对话/约定"，发送前还会检查草稿。但 fish_heart **不存记忆**——只有这条私聊时间线和 AstrBot 的历史。要真的"记得住"，请配记忆插件。

**她在群里不认我？**
检查 `perception.owner_ids`。留空时会从 `target_umo` 末段反推；如果 `target_umo` 填的是群 UMO，推导会被跳过（群号不是人）。

**她说话怎么不分条？**
这句话里没有句末标点（切不出多段就原样发一条）。分段发送已固定开启。

**面板打不开 / 读不到状态？**
先确认 AstrBot ≥ 4.24.2，再确认插件已重载。4.24.2–4.25.2 只有插件详情页的「页面 → 打开页面」，侧边栏没有入口。4.29+ 仍看不到，访问 `http://<地址>:6185/api/plugin/detail?name=astrbot_plugin_fish_heart` 看 `pages` 字段。

**改完配置要重启吗？**
改 `state` 相关不用；改插件代码或 `_conf_schema.json` 需要重载插件。
