# 鱼的心 · astrbot_plugin_fish_heart

给她一颗**会变的心**，而不是一堆记忆。

AstrBot 4.x 插件，纯标准库实现，不依赖任何第三方包。

> 和"记忆插件"的分工：记忆插件负责**她记得什么**，鱼的心负责**她此刻是什么心情、在惦记什么**。
> 两者互不改写——本插件不建第二套记忆、不碰任何已有记忆数据。

> **0.3.9 重点**：**群友模式成了独立配置卡**：配置页新增「👥 群友模式」一段，开关、鱼主/群友的正负强度、主动私聊比例（`group_mode.dm_ratio`，0–1，默认 0 = 只发群，0.3 就是三成主动消息走私聊，找不到私聊地址就回落到群里、绝不发给群友）都收在这一张卡里；旧配置里的 `perception.group_everyone` 等键第一次启动会自动并进来。**新增「睡前兜底」**（`proactive.daily_guarantee`，默认关，在配置页打开）：当天一次都没主动说过话时，从她睡前 30 分钟起跳过随机概率，必定尝试一条；睡着/回避/刚聊过 10 分钟内仍会挡住，条件解除且还在窗口内才补。**含蓄夸奖也算数了**：`你真是我的小棉袄` / `你真贴心` / `真乖` / `乖` 不再被当成普通说话，按明确夸奖的约 55% 结算，并喂饱「想被夸」；`不乖`、`我女儿真贴心`、`真好吃`、`乖，别闹了` 不算，可用 `perception.praise_soft` 关掉。**夸多了她会腻**：同一人 30 分钟内第 3 次夸降成「听腻了」、第 5 次起「夸过头了」（喜悦 −1、压力 +2），嘴上会拆穿你，但不进责怪档、不扣依恋；可用 `perception.praise_fatigue` 关掉。另修状态提问误记轻责：`你怎么醒了 / 你怎么还没睡 / 你怎么来了 / 你怎么这么晚才回来`；`你怎么能这样 / 你怎么不早说` 仍按轻责算。
>
> **0.3.8 重点**：责怪判断改为“小句目标 + 第三方/转述过滤”，`他就是个傻逼，你不用管他`、`我室友说你笨` 不再算责怪；`你怎么知道/发现/看出` 这类信息提问不再误记轻责；新增可选 `perception.blame_judge`（默认关），只对规则没判出的模糊句额外问一次 LLM。
>
> **0.3.7 重点**：主动消息改为读**带时间戳的对话时间线**（每条 `[月-日 时:分]`，私聊优先用插件自己的 `recent`，群流水/已读不回/群凶句也带日期）；不再用「先说你这边，刚收拾完/刚看到什么」这类模板诱导编近况；发送前会自检草稿是否和最近聊天矛盾。同时修复 `/心 tick` 或面板「替她跳一次心跳」时，`proactive.target_umo` 只填 QQ 号/群号/半截 UMO 导致的 `不合法的 session 字符串：not enough values to unpack (expected 3, got 1)`——发送前校验 `platform:MessageType:session_id`，格式不对就跳过并写清怎么改。群聊里的 `/心 status/calm/reset/tick/off/on` 只对 `perception.owner_ids` 里的鱼主开放（`/心 umo` 除外），`group_everyone` 不会放开命令权限。另新增 `diagnostics.log_affect` 开关（默认关闭）：打开后每条对话写一行 JSON 影响日志，含原文、事件、实际增量和前后状态，负向会标出来。状态显示改成两层：**心情**（黏人/开心/累了/紧绷/走神/好奇/平常）+ **责怪档**（日常/委屈/生气/害怕/回避）；原来的“平静”改叫“日常”，表示没在生气，不再当成完整心情。另新增隐藏属性 **「欲」**：依恋、亲密都到 80 并持续 24 小时才解锁；只在私聊鱼主生效，`/心 status` 不显示数值，WebUI 解锁后由「隐藏的欲」卡片显示；成人向身体层还要 `desire.adult_enabled` + 私聊鱼主 + 当前场景明确同意（`/adult on` 只是 24 小时预授权，不是必需）。解锁后 WebUI 会在六张卡之后出现横跨整行的「隐藏的欲」卡片，显示数值、阶段、成人层状态和最近涨落。

## 1. 它做什么

### 九维驱动

| 维度 | 静息基线 | 说明 |
|---|---|---|
| 依恋 attachment | 45 | 想不想你 |
| 好奇 curiosity | 55 | 想不想知道 |
| 反刍 reflection | 50 | 会不会反复想同一件事 |
| 责任 duty | 50 | 想不想做事 |
| 社交 social | 45 | 想不想说话 |
| 疲惫 fatigue | 20 | 累不累 |
| 亲密 intimacy | 40 | 情绪/身体上的亲近感 |
| 压力 stress | 15 | 紧张、不安 |
| 喜悦 joy | 50 | 开心程度 |

所有维度都会**慢慢回落到基线**：情绪类 5%、其他 3–4%、**依恋和亲密只有 1%**。
最后这两个是"存量"——每天能加的就十几点，用情绪的速度去回落（一天 20 点）它们永远只能趴在基线上。
1% 意味着**冷淡一周就从 66 掉到 47**，明显疏远，但不会一夜清零。
**关机/重载期间错过的回落会补算**：心跳按"距上次心跳过了几个间隔"一次性折算（上限 96 次 ≈ 3 天），
否则关一夜回来只算一次心跳，情绪几乎不动。耦合、念头、睡眠判定仍然只跑一次。
维度之间还有耦合：依恋高会推亲密，压力高会压喜悦，疲惫高会压好奇。
依恋↔亲密是**互相拉齐、但不会把对方拖过自己**（原来无条件 +1.5/心跳，会互相喂到 100）。
耦合**按超出阈值多少成比例**，不是一过线就每个心跳扣固定值——否则疲惫一旦超过 60，
好奇会被一路按到 20 以下、而且再也爬不回来（0.3.2 之前就是这样）。

每个维度都有实际输入：

| 维度 | 谁在推它 |
|---|---|
| 依恋 | 夸奖、哄、撒娇；她开口后你及时回。**闲聊不加**——依恋得靠具体的话 |
| 好奇 | 日常对话；你发图 / 链接 / 分享新东西 |
| 反刍 | 被责怪、被她等太久 → 涨；被哄、被道歉 → 落 |
| 责任 | 你求助（"帮我看看""怎么办"） |
| 社交 | 你说的每一句话 |
| 疲惫 | 连续聊天累积（每条 +0.6、求助 +1.5，**越累边际越小**）；安静时回落，**安静 6 小时算睡了一觉** |
| 亲密 | 夸奖、撒娇、及时回；**闲聊每句 +0.1**——关系靠"天天说话"慢慢变深 |
| 压力 | 被凶、被敷衍 → 涨；被哄、被夸 → 落 |
| 喜悦 | 几乎所有正向互动 |

每个维度都有自己的**天花板**（`DIM_CEILING`，默认全是 **100**）：增益按 `1 - 当前值/天花板` 缩放，
所以越往上越难——**100 是渐近线，永远差最后一点点**，不是靠"改刻度"造出来的假上限。
疲惫和压力不做这个抑制——它们是代价，累了就是累了。

### 正向增益的节奏：同类事件会"退热"

只靠上面那个递减还不够——它是按「离 100 多近」压的，可是增益本身是**按消息条数线性**累加的：
你连发 30 条，就等于发生了 30 件事，一晚上就能把社交顶到 70。

所以多了一道**热度折扣**：同一类事件在 10 分钟内第 n+1 次发生时，增益按 `1 / (1 + n/12)` 缩水。

| 10 分钟内第几条 | 增益 |
|---|---|
| 1 | 100% |
| 7 | 63% |
| 13 | 48% |
| 25 | 32% |
| 49 | 20% |

- 它是**按事件类型**算的（群友模式的负面情绪是另一套，按来源分桶，见下面的「群友模式」）
- 只压**正向**增量。私聊 / 非群友模式里的责怪、压力、疲惫照旧累加（三句重责照样打进回避），疲惫甚至故意不抑制；**群友模式**下负面情绪会按鱼主 / 群友两个桶分别递减
- 是"别一晚上聊满"，不是"永远涨不动"：隔十几分钟再聊，热度就退回去了

实测（40 秒一条、45 分钟一次心跳，同一套脚本对跑）：

| 场景 | 喜悦 | 社交 |
|---|---|---|
| 基线 | 50.0 | 45.0 |
| 连聊 30 条（约 20 分钟） | 63.0 → **57.7** | 70.0 → **59.3** |
| 30 条含 3 次夸奖 | 70.3 → **65.3** | 68.1 → **58.6** |
| 连聊 60 条后安静 1.5 小时 | 70.4 → **61.7** | 80.6 → **66.2** |
| 社交涨到 90 需要 | 90 条（1 小时） | **465 条（5.2 小时不间断）** |

调法：`HEAT_WINDOW_SEC`（窗口，默认 10 分钟）和 `HEAT_DIVISOR`（默认 12，越大越不压）。
面板的「最近的变化」现在显示的是**实际生效**的增量（已经过渠道权重、天花板衰减、热度折扣和每日上限），
所以你会看到「说话 社交 +1.1」这种，而不是名义上的 +2.0。

### 每日收益上限（养成难度）

再叠一道**按天的硬闸**：`DAILY_GAIN_CAP`——喜悦 40、社交 40、好奇 30、亲密 40、依恋 40。
只统计**正向**增量、只对白名单里的他生效、按本地自然日清零。额度用完后，当天再聊也不会更开心。

它和天花板分工不同：天花板决定"越往上越难"的曲线，每日上限决定"一天最多涨多少"。

三天实测（每天 50 / 100 / 300 条）：

| 每天用量 | 喜悦 | 社交 | 40 的额度撞到了吗 |
|---|---|---|---|
| 50 条 | 70.5 | 75.0 | 没有 |
| 100 条 | 77.6 | 82.3 | 没有 |
| 300 条 | 83.2 | 88.1 | 擦边 |

也就是说：**正常到重度用量下，40 的上限基本撞不到**——真正压住她的是回落和热度。
把上限压到 24 以下会开始出现**倒挂**（聊 100 条的人反而比聊 50 条的低），
因为多聊的时间全用来回落、额度却早就用完了：

| 上限 | 50 条 | 100 条 | 300 条 |
|---|---|---|---|
| 10 | 62.4 | 55.3 | 57.2 |
| 16 | 67.0 | 60.0 | 62.3 |
| 22 | 69.1 | 66.1 | 68.4 |
| 30 | 70.5 | 76.9 | 81.0 |

所以上限保持在 40，当"防一天刷爆"的保险丝；想要纯正的每日封顶就往下调，但要接受倒挂。

面板的「主动说话」卡片多一枚「今日收益」胶囊，`/心 status` 也会显示当天已用额度，
所以"今天还能涨多少"是看得见的。

### 疲惫：边际递减 + 睡一觉

疲惫是唯一"不抑制"的代价维度，但它也因此最容易顶死——`+0.6/条` 是线性的，
150 条/天上午就能顶到 100，之后一整天都是「累了」，睡一觉也只是把时间线推回原点。

现在两处改法：

1. **边际递减**：`delta *= max(0.25, 1 - 0.5 × 当前疲惫/100)`。基线 20 时一条 +0.51，
   疲惫 90 时只有 +0.33，留 25% 的下限保证长聊仍然比短聊累
2. **睡一觉**：安静满 6 小时（不看时段，所以午休也算），疲惫直接回落到 35

三天实测（每天 3 段 × 50 条 = 150 条，段间 3 小时，夜里 8 小时）：

| 时点 | 疲惫（改前 → 改后） | 状态 |
|---|---|---|
| 第 1 天第 2 段结束 | 73.3 → **62.0** | 累了 → 平常 |
| 第 1 天第 3 段结束 | 92.9 → **74.1** | 累了 |
| 第 1 天早上 | 63.6 → **29.5** | 平常 |
| 第 2 天第 3 段结束 | 100.0 → **78.2** | 累了 |
| 第 3 天第 3 段结束 | 100.0 → **78.2** | 累了 |

每天都是同一条弧线：早上 29 → 第一段 45 → 傍晚 78，不会一天比一天更累。
300 条/天的极端重度用户也是早晨 29.5、峰值 94，不再钉死在 100。

另外，疲惫 > 70 时主动说话的意愿会往下压（最多压到 15%），但**「忍不住想他」那种除外**——再累也会想找你。

### 关系（依恋 / 亲密）：慢回落、轻打击、会侵蚀

这两个维度不是"情绪"，是"存量"，所以规则不同：

| | 做法 | 为什么 |
|---|---|---|
| 回落 | **1%**（情绪是 5%） | 每天能加十几点，用 5% 掉（一天 20 点）就永远攒不起来 |
| 一句重话 | 依恋 **-3**（中责 -1.5），**亲密不扣** | 该疼的是情绪，不是关系。当场把依恋砍掉就只剩生气，出不来"又气又想你" |
| 一直凶 | `blame ≥ 55`（生气/害怕/回避）时，每心跳依恋、亲密各 **-0.15** | 吵一次就停手，blame 会褪到 40（心结）→ 侵蚀停止；一直凶才会把关系磨没，一周约 -35 |
| 矛盾 | `blame ≥ 25` 且依恋/亲密 ≥ 55 时，注入「心里矛盾：还在生他的气，可你又不想他真的走。」 | 不写出来，模型只会演"生气"这一半 |
| 阈值 | 黏人 **66/66**、想亲近 **62**、抱抱念头 58、想他念头 50、longing 60 | 原来是 80/80，配平后永远到不了，等于死代码 |
| 面板 | 依恋/亲密**归一到 0–100 显示**（真实 80 = 显示 100，真实 72 = 显示 90），其余维度本来就是 0–100 | 实际到不了 100，不归一的话这两条永远是半截，数字也永远看着"没养满" |

实测（每天 100 条、每 10 条一次夸奖）：

| 场景 | 依恋 | 亲密 | 心情 |
|---|---|---|---|
| 起点 | 45.0 | 40.0 | 平常 |
| 第 3 天 | 62.2 | 72.9 | 想亲近 |
| 第 4 天 | 69.7 | 76.4 | **黏人** |
| 第 7 天 | 77.4 | 80.5 | 黏人 |
| 之后一周不聊 | 66 → **47.2** | 66 → 42.7 | 平淡 |

也就是说：**养到"黏人"要四五天的持续亲密**，停下来一周就明显疏远——这才是养成的节奏。

### 两条快变量

- **期待值 expectation**：她主动开口后你一直没回，就会慢慢涨；你一回应就大幅清零。
- **责怪压力 blame_pressure**：你凶了她才会涨，决定她当前处在哪个档位。它**没有"自己涨"的机制**——只有你说的话被判成责怪/敷衍时才会加上去，没人说话时只会往下褪。

### 五档状态

> **显示说明**：calm 档在面板和 `/心 status` 里显示为 **「日常（没在生气）」**，不再叫“平静”。它只说明责怪 <25，不说明她现在开心、黏人还是累了；后者看「心情」标签。文档里为了说明阈值，仍会写“日常/平静”两种叫法。

| 档位 | blame 区间 | 表现 |
|---|---|---|
| 日常 calm（旧的“平静”） | < 25 | 正常说话；具体是黏人/开心/累了/走神，看「心情」 |
| 委屈 wronged | 25 – 55 | 话变短，会先问你一句"是不是嫌我烦" |
| 生气 angry | 55 – 70 | 会回，但冷、短、带刺；把刚才那句挑明，要你解释/道歉；**不会消失**，也可能冷着主动开口 |
| 害怕 afraid | 70 – 80 | 不顶嘴，先确认你还想不想跟她说话 |
| 回避 shut | ≥ 80 | 少说，不讨好，也不追问；**主动说话会被冻结**，你连发的话前 5 条一律不接（第 7 条必回）；群里只多放行 1 句 |

- **重责不跳档**：从日常/委屈被一次重责打到 70 以上时，最多停在 **69（生气上沿）**，下一次责怪才可能进害怕/回避；已经处在生气/害怕的人不受这个封顶影响。
- **替她出头不算责怪**：`谁骂你笨，就骂他杂鱼`、`他欺负你，我帮你骂他` 这类会先把“谁/他 + 骂/说/欺负/惹/凶 + 你”的从句摘掉；同一句里如果还有 `你真笨`、`你真是个废物` 这种直接骂法，仍会照常记。
- **第三方/转述不算责怪**：`他就是个傻逼，你不用管他`、`那不是我说的，是我傻逼室友说的，你记账记他的去，别记我的`、`我室友说你笨` 不再记成责怪。这里不枚举“室友/同事/朋友”等角色，而是按小句结构判断：同一小句没有“你”、也不是对她说的祈使句（如“闭嘴/滚/别烦我”），就跳过；“某主语 + 说/骂/讲/嫌/觉得/吐槽/抱怨 + 你”这种转述也跳过；同一小句明确有“你”的直接骂法仍照常记。
- **信息/状态提问不算轻责**：`你怎么知道 / 怎么发现 / 怎么看出 / 怎么判断 / 怎么确定 / 怎么会知道`，以及 `你怎么醒了 / 你怎么还没睡 / 你怎么来了 / 你怎么这么晚才回来` 都是提问，不记责怪；`你怎么能这样 / 你怎么不早说` 仍按轻责算。
- **生气按人拆**：群友模式下谁对这次生气有贡献，谁就是生气对象（`anger_targets`，12 小时有效，可同时有多个）；A 惹了她，B 再说话时看到的是**委屈**，只有 A 会看到**生气**；如果 B 随后也说了责怪/敷衍的话，B 也会成为第二个对象。B 的安慰/道歉不能替 A 消气；A、B 都是对象时，B 道歉只解除 B，最后一个对象道歉后才真正降全局责怪。

她知道**真哄**和**敷衍**的区别：

- 真哄要连续哄够轮数才生效（日常 1 轮 / 委屈 1 轮 / 生气 1 轮 / 害怕 2 轮 / 回避 2 轮）
- **生气档只认道歉或"把话说清楚"**：只说"抱抱""乖""别生气"不算进度，先抱一下但没解释，她还是会冷着；道歉/解释一轮就能把火降成委屈，再一轮才回到日常
- **"说清楚"的判定**：除了"听我解释 / 我不是那个意思 / 我刚才在… / 不是故意"，现在还认"我刚刚在… / 我当时… / 我当时在… / 手机没电 / 手机静音 / 没看到消息 / 没来得及回 / 你先听我说"等第一人称解释；仍是关键词判定，不是语义理解
- 一边哄一边"行了别闹"式的敷衍，会被判定成敷衍式哄——哄的进度作废，压力反而上涨
- 没人哄时压力每 6 小时才褪一点，而且**止于 40（心结）**，不会自己好干净
- 卡在 40 就是"心结·旧账"：面板的档位会写成**委屈·旧账**，"此刻"里那行责怪也会说明"不哄不会掉"，`/心 status` 会直接写「需哄/道歉/说清楚，或 `/心 calm` 才能解」
- 不甘心等：`/心 calm` 只清责怪和心结，九维一条都不动（`/心 reset` 是整颗心重置）

### 回避档的已读不回

进了**回避**档（责怪 ≥ 80），她不只是不主动开口——你连发的话，她也按阶梯接：

| 你发的第几条 | 她回的概率 |
|---|---|
| 第 1–5 条 | **0%，一条都不回** |
| 第 6 条 | 50% |
| 第 7 条起 | **100%，必回** |

- 阶梯写死在 `SHUT_REPLY_LADDER`（`main.py` 顶部），改一行就能调；整段关掉用 `shut.enabled = false`
- **群聊也走阶梯，但多给一句**：刚被打进回避的那一下，她在群里还会回你那句（受伤的反应），之后才闭麦——之后群里同样前 5 条不回、第 6 条 50%、第 7 条必回（`SHUT_GROUP_GRACE = 1`）
- **私聊和群聊各算各的**（`silent_streak` / `silent_streak_group`）：你在群里冷了她 5 条，切到私聊仍然从第 1 条开始算，不会互相吃额度
- **这 7 条一条不丢**：被她无视的每一条都按原话存着（最多 7 条），等她终于开口时**一次性全部交给她**
- 交给她时会明确要求**先归纳、再回**：「先把这几条连起来读一遍……在心里归纳成一句话，再回他。不必逐条回应，也不必解释自己为什么沉默。」——所以她回的是"这几条合起来在说什么"，不是挑最后一条敷衍
- 两条必回（写死）：**命令**（`/心 status` 之类，否则你连诊断都做不了）、**真哄 / 道歉 / 说清楚**（她可以冷着脸，但不能让心结永远解不开）
- 每次不回都记在对应的 streak 上，出了回避档或终于回话时自动清零；`/心 status` 与面板显示「私聊 N/7 · 群聊 M/7｜私聊下一条回的概率 X%」
- 阶梯走到第 7 条就必回，所以**不会真的无限沉默**；想让她更早心软，把 `SHUT_REPLY_LADDER` 里的 `0.0` 改小或往前挪 `0.5`

> 注意：被她无视的那几条不会进 AstrBot 的对话历史（请求被直接终止了），所以插件自己存了一份，靠第 7 条那次注入补回去。补回去的是**原文**，不是"她说她记得"。

### 群聊 → 私聊：她为什么被凶

群聊和私聊是两个独立的 AstrBot 会话，两本账不互串。所以你在群里凶完她、切到私聊，她原本只知道自己"被重责了"（责怪压力真的涨了），**不知道因为哪句话、更不知道前因**。

插件在群里维护一条**群聊流水**（谁说的 + 说了什么，最近 8 条），在你凶她的那一刻，把**触发句 + 前面 3 条**快照下来（滚动 5 组、12 小时内有效），私聊时补给她：

```
## 群里刚才发生了什么（你因为这些被凶了）
- 21:36 他：周末一起去看展吗
- 21:38 你：我不想去，你自己去吧
- 21:39 群友：你们俩又吵什么
- 21:40 他：你他妈能不能别恶心人　← 就是这句
这是背景，不是要你复述。你现在还在生气/委屈，知道自己在气什么、气哪一句，就够了。
```

- 流水里三个人称都记：**他**（白名单）、**你**（她自己，来自她的群回复）、**群友**（其他人在群里说的话）
- 只有**他命中负向词**那一刻才快照，平时不记进 `group_blames`；群友的普通闲聊只在流水里滚动，除非正好落在某次"凶她"的前因里
- 只进**私聊**注入，群里不给（群里她自己就在场）
- 12 小时过期；她回到**日常**时自动清空，不会在没事的时候还挂着旧账
- 它可以和「被你无视的 7 条」同时出现，两者是不同的事实：一个是"你为什么生气"，一个是"你刚才没接的话"
- 你在私聊里打的**解释**也不会白费：前 5 条她虽然不回，但每一条都记进 `unanswered`，第 6/7 条开口时会和群里那段前因一起交给她

### 念头

十类小念头：想被夸、想被抱、想找他说话、想问他今天怎样、想找点事做、想安静一会儿、想撒娇、想让他陪一会儿、想问他一件关于我们的事、在等他回话。

念头会**挂一段时间**（1.2–4 小时不等）、会被你的话**喂饱**（喂饱后留下"心情"，写进心境）、也会**凉掉**（没被满足就轻微回落）。她主动开口时，会优先围绕正在惦记的那条念头。

每条念头认的话不一样，完整清单：

| 念头 | 完成条件 |
|---|---|
| 想被夸 | 明确夸她：`厉害` / `真棒` / `太棒` / `优秀` / `了不起` / `可爱` / `喜欢你` / `爱你` / `谢谢` / `夸` / `你真好`；含蓄夸她也算（约 55% 份量）：`小棉袄` / `贴心` / `懂事` / `温柔` / `体贴` / `真乖` / `乖` |
| 想他 | 明说：`想你` / `想我` / `有没有想我` / `惦记` |
| 抱抱 | 哄她或抱：`抱` / `贴贴` / `搂` / `亲亲` / `撒娇` |
| 想讲 | 普通回一句就行 |
| 问他今天 | 普通回一句就行（`过得` / `怎么样` / `还好吗`…） |
| 想做事 | `帮我` / `安排` / `需要我` / `帮个忙`；或责任 ≤40 自动完成 |
| 想安静 | `歇` / `休息` / `睡` / `安静` / `别忙了`；或疲劳 ≤45 且压力 ≤35 自动完成 |
| 等回话 | 他及时回（30 分钟内） |
| 陪一会儿 | 回一句，或 `陪你` / `陪陪` / `聊会儿` / `说说话` |
| 走心 | 回一句就行 |

**一轮最多完成一条**：你一句话只会喂饱最想要的那一条，不会一次把列表清空；而且完成一条后会进入冷却（`settle_cooldown_minutes`，默认 10 分钟），冷却中再说也不会完成下一条。普通回一句能完成「想讲 / 问他 / 想做事 / 安静 / 陪一会儿」里的一条；「想被夸」要夸、「想被抱」要哄/抱、「想他」要明说想你。群聊里只有**白名单里的他**能完成念头；开了群友模式后群成员才算，关着时群友的话只加热闹。另外「安静」「想做事」会在疲劳/压力或责任降下来时**自己缓过来**（不带奖励，面板标「自愈」），主动开口三次没被接住会变成「算了，先不想了」。面板会在每条 pending 念头下写**满足条件**，念头列表可滚动；**最近完成 / 自愈 / 最近放下**在页面最顶部的卡片里，**2 小时内最多 5 条、卡片封顶 260px、超出在卡片内滚动**，超过 2 小时自动隐藏。

**台阶只在主动说话时出现**：`如果想让他接住，可以往这个方向递话：…`，按类型配了 10 条**方向**（不给固定例句，明确要求用她自己的话、别照抄），后面跟"台阶不是台词：上面只是方向，用你自己的话，别照抄；今天没有对应的事就别编，不想提也可以不提。他没接住就算了，别追问"。正常聊天**不注入台阶**，只保留"心里惦记着：…"。**每条念头只提示一次**；这句只进 prompt，面板不显示。

### 心境注入

每轮请求前，把当前心境追加到系统提示词末尾（只追加、不覆盖别的插件）：

```
## 你此刻的心境（内部状态：不要主动复述，但它会左右你的语气）
责怪档：日常｜心情：平常｜依恋 45 亲密 40 压力 15 期待 0
倾向：语气自然就好，顺着当下的心情来
边界：不要编造没发生过的对话、约定或事件；记不清就说记不清
心里惦记着：想知道他有没有想我
```

> 「倾向」在**注入**里是完整的说话指令；在 **Web 面板 / `/心 status`** 里只显示一句短描述（如"这会儿特别想黏着他"），不会把给模型看的指令摆到界面上。
>
> **欲解锁后**：正常聊天默认**每 5 分钟最多追加一次**“主动一点”的提示，不受上面的 20 分钟心境节流；主动消息每次都走同一段提示的主动版。它只写定性方向，不显示数值。**睡着、压力 ≥50、疲惫 ≥65 时不注入。** 间隔可用 `desire.inject_interval_minutes` 调，填 `0` = 每轮都注入。例如：
>
> ```text
> 你现在有点想他靠近；可以主动一点、软一点，接住他的话，
> 也可以提议两个人独处一会儿；先看他接不接，别把话说成要求。
> ```

**跨档必注**：档位变了（日常 → 委屈 → 生气 → 害怕 → 回避）就一定注入，不受间隔限制——档位是行为开关，漏报会让她"不知道自己已经在生气了"。
**同档内的数值漂移**才按 `min_gap_minutes` 节流（默认 20 分钟）。
**生气档例外**：只要当前对这个人还是生气，每轮都会重新注入——否则下一轮 system prompt 里没有心境块，她会把上一轮的生气忘掉，按常态说话。
节流状态**按会话各记一份**——私聊和群聊都能各自看到当前心境，不会互相抢。

### 主动说话

由情绪驱动，不是定时打卡：

- 六型动机：`longing`（很想他，忍不住先开口）、`waiting`（等了很久，想知道他还在不在）、`whim`（突然想起一件小事）、`company`（想让他放下手里的事陪一会儿，但不许指责）、`deep`（认真问一件关于你们俩的事，不是查岗）、`angry`（还气着，冷着问他刚才那句话什么意思）
- `company` 只在**日常档 + 黏人（依恋、亲密都 ≥66）+ 期待 ≥30 + 不累**、并且心里正好惦记着"想让他陪一会儿"时才会用——先递一句软话，等不到才"陪我说会儿话吧"；你一回应期待就回落，下一次又回到 `longing`，不会句句都要人陪
- `deep` 只在**日常档 + 反刍 ≥55 + 依恋 ≥55 + 不累**、并且心里正惦记着"想问一件关于我们的事"时才用——问的是"你觉得我们现在这样好吗""你跟我在一起开心吗"这类，不是查岗、也不要保证；反刍只靠被凶/被晾上涨，所以正常聊天里它不会天天出现
- `angry` 只在**生气档（55–70）**出现：她可能主动找你，但方向是问清刚才那句、要个说法，不是撒娇；按**这个生气对象**最近一次责怪过去多久分三种语气（3 小时内更冲 / 3–12 小时淡一点 / 12 小时以上还记着但不故意刺），概率最高 45%，不占用念头限流
- **开头不固定问"忙不忙"**：`longing` 会按期待/依恋和时段（早上/下午/晚上/深夜）在「直接说想他 / 问一句今天怎么样 / 撒个娇」里选方向；`waiting` 先看记录里他最后说了什么，能接就接，没有可接的直接问，**不再要求"先说自己这边"**；兜底台词也不含"在忙吗 / 有空吗"，并会避开上一次主动说的那句和同样的开头
- 开口概率随依恋、期待、亲密、社交上涨，随疲惫下降
- **读带时间线的真实对话**再开口（双方的话都在）：每条记录前带 `[月-日 时:分]`，按时间从早到晚排列；私聊优先用插件自己的 `recent`（每条有 `ts`），AstrBot 历史没有可靠时间戳时标 `[时间不详]`，不会假装知道"刚刚"
- 说完**回写对话历史**——不会"说完就忘"
- 一次可以说 1–3 句（总共 ≤60 字），多句时拆成 2–4 条发送，条间隔 0.8–3.5 秒，像人在打字
- LLM 不可用时退回内置兜底台词，保证不会一声不吭
- **不会拿"编出来的回忆"接话**：主动消息只引用真实对话记录（没出现过的事不编时间/地点/约定），没有记录时宁可只问不陈述；"心里惦记着"只是此刻的念头，不是发生过的事。模板也不再诱导"刚收拾完/刚看到什么"这类具体近况
- **发送前自检**：如果草稿声称了记录里没有的第一人称近况（例如他刚说"吹完头发、躺下、晚安"，她却说"我刚吹完头发"），或他最后已经说要睡/在忙、她还问"在干嘛/睡了吗/忙不忙"，会先重写一次；仍冲突就换成不声称任何近况的兜底。检查只做可证明的判断，不猜语义
- **回避档下主动说话被硬冻结**（连开机补发也不破例）——那时候不是"不想你"，是"不想先低头"；**生气档不冻结**：她可能主动开口，但更像冷着问一句"你刚才那句话什么意思"，不是撒娇，也不是装没事

## 2. 安装

1. 把 `astrbot_plugin_fish_heart` 整个目录放到 `AstrBot/data/plugins/`
2. 重启 AstrBot（或在插件管理页重载）
3. 打开插件配置，至少填好 **目标会话 UMO**

查询 UMO 的方法：在目标会话里发 `/心 umo`，把返回的那串填进配置。

要求 AstrBot `>= 4.24.2`，平台 `aiocqhttp`（OneBot v11）。

原因是**插件页面**（WebUI 视图）从 4.24.2 才有，而且目录名变过：

| AstrBot | 页面目录 | 入口 |
|---|---|---|
| < 4.24.2 | 没有这个能力 | 无 |
| 4.24.2 – 4.28.x | 只认 `pages/<名字>/` | 插件详情页「页面」；4.25.3 起侧边栏也有 |
| 4.29.0 起 | 优先 `views/`，`pages/` 作为兼容别名 | 侧边栏「扩展功能」/ 详情页 |

所以插件同时带了 `views/heart/` 和 `pages/heart/` 两份（内容一致，靠 `tools/sync_pages.py` 同步），并把版本下限标成 4.24.2——装在 4.16–4.24.1 上会直接提示不兼容，而不是"装上了却没有界面"。

## 3. 配置

### 总开关

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关掉后不心跳、不注入、不主动说话，已有数据保留 |

### 心境注入 `inject`

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 是否把心境写进系统提示词 |
| `min_gap_minutes` | `20` | 两次注入的最小间隔（分钟） |

### 心跳 `tick`

| 键 | 默认 | 说明 |
|---|---|---|
| `base_interval_minutes` | `45` | 常规心跳间隔 |
| `min_interval_minutes` | `15` | 最短间隔；压力/责怪越高心跳越快 |

### 主动说话 `proactive`

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 允许她主动开口 |
| `cooldown_hours` | `6.0` | 两次主动说话的最小间隔 |
| `daily_limit` | `4` | 每天最多说几次 |
| `min_idle_minutes` | `10` | 你刚说完话多久内不打扰（按**私聊**算） |
| `daily_guarantee` | `false` | **睡前兜底**：当天还没主动说过话时，从她**睡前 30 分钟**起跳过随机概率，必定尝试一次。睡着/回避/目标没配好/刚聊过 10 分钟内仍会挡住，条件解除且还在窗口内才补；**群里一直有人说话时，因“刚聊过不打扰”仍会挡住，保底可能发不出**。在配置页 `proactive.daily_guarantee` 打开。关掉作息时，当天第一次心跳就补 |
| `catch_up_on_start` | `true` | 开机补发错过的主动消息（**同样遵守冷却/日限/作息/回避状态**） |
| `segment_reply` | 固定开 | 多句时拆成几条发（按句末标点切 2–4 条，条间隔 0.8–3.5 秒）。**已从配置页移除**，不再提供开关；旧配置里手动写成 `false` 仍会被尊重 |
| `target_umo` | 空 | 主动消息发往哪个会话；留空 = 自动记住最近跟她说话的会话。必须是 `platform:MessageType:session_id` 三段，只填 QQ 号/群号会跳过发送并写日志 |

> `company`（求陪伴）和 `deep`（走心）默认开启，但**不在配置页展示**——这两类属于角色本身的行为，不需要日常调。想单独关掉，在配置 JSON 的 `proactive` 里手加 `"company": false` 或 `"deep": false` 即可（代码里读的是同名键，缺省为 true）。

### 作息 `sleep`

默认开启（`enabled: true`）：23:30 睡、07:30 起，每天有 20% 概率熬夜 2 小时。不想要就关掉或改时间。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 启用作息 |
| `bedtime` | `23:30` | 入睡时间（HH:MM，按本地时间） |
| `wake` | `07:30` | 起床时间（HH:MM） |
| `stay_up_chance` | `0.2` | 每天熬夜的概率；每天第一次用到作息时掷一次 |
| `stay_up_hours` | `2.0` | 熬夜那天把入睡时间往后推几小时 |

她睡着时**不会主动说话**（哪怕开机补发）；你发消息会把她吵醒——每 30 分钟只算一次"被吵醒"（压力 +2、喜悦 −1、疲惫 +1，不算责怪），回复口气按九维走：

- 疲惫 ≥70：回得很短、有点迷糊，句子可能不完整；
- 压力 ≥50：被吵醒有点烦，语气冲一点；
- 依恋/亲密 ≥66：嘴上嫌烦，但还是会回。

面板「主动说话」里的「作息」胶囊会显示 `23:30-07:30`、`睡着（07:30 起）` 或 `… 熬夜`。

> **0.3.4 起 `proactive.quiet_hours` 已移除**：睡觉与静音统一由 `sleep` 管，不要再单独配「免打扰时段」；旧配置里的 `quiet_hours` 会被忽略。

### 情绪感知 `perception`

| 键 | 默认 | 说明 |
|---|---|---|
| `owner_ids` | `[]` | 谁的 QQ 号能影响她的心。**留空自动从 `target_umo` 末段反推**（仅限私聊 UMO） |
| `blame_judge` | `false` | 可选 LLM 兜底：只对“有责怪词、但规则没判出”的模糊句额外调用一次当前 LLM，判断对象是鱼 / 第三方 / 自嘲 / 不确定。会多一次调用、延迟和 token；失败/超时回退规则。成人同意不参与 |
| `praise_soft` | `true` | 把含蓄夸奖（`小棉袄` / `贴心` / `真乖` / `乖`）也算作夸奖，约 55% 份量 |
| `praise_fatigue` | `true` | **夸多了会听腻**：同一个人 30 分钟内第 3 次起降成「听腻了」，第 5 次起「夸过头了」（喜悦 −1、压力 +2），她嘴上也会拆穿他；不进责怪档、不扣依恋。按说话人分桶，`抱抱/想你` 这类由哄映射的夸奖不算 |
| `outsider_effect` | `social_joy_only` | 别人的话对她的影响：`social_joy_only`（社交 +2、喜悦 +1）或 `none`（完全忽略）。**只在群友模式关闭时对群聊生效**；开启后群聊里没有「外人」，这一项只剩私聊陌生人会用 |

**升级 0.3.5 → 0.3.6**：如果配置里 `perception.group_negative_scale` 仍然是 0.3.5 的旧默认 `0.8`，第一次启动会自动改成 `0.35` 并写回配置（只做一次；之后手动改回 0.8 会尊重）。其他显式值不动。

**这套白名单是双向生效的**：

- 私聊：只有白名单里的号能改变她的心；陌生人私聊只加热闹度
- 群聊：同上；判发送者 ID（群聊 UMO 末段是群号，认不了人）
- 如果 `owner_ids` 和 `target_umo` 都为空：**私聊仍放行、群聊按外人处理**（0.3.3 起，之前是"全放行"）
- 例外：`group_mode.enabled: true` 时群聊不再看白名单，全群都能影响她（正向按 `group_mode.member_scale`，负向群友按 `group_mode.member_negative_scale`、鱼主按 `group_mode.owner_negative_scale`），此时 `outsider_effect` 对群聊不再生效；详见下面的「群友模式 `group_mode`」

### 群友模式 `group_mode`

给「她主要活在群里」的部署用：打开后群聊里**所有人**的话都按「他」处理，能改九维、能哄能气；关着时群聊只认 `perception.owner_ids` 里的鱼主，名单外的群友只加热闹。对所有群生效。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `false` | **开启群友模式**：群聊里任何人的话都按「他」处理。注意开了以后群友随口「烦死了」「滚」也会算责怪（关键词过滤仍在），影响多大由下面的强度决定 |
| `owner_scale` | `1.0` | 鱼主的**正向**强度（0.05–2.0）。命中 `owner_ids` 时按这个系数算，默认 1.0 = 私聊强度，**不乘群聊渠道权重** |
| `member_scale` | `0.5` | 群友的**正向**强度（0.05–1.0）：群里的夸奖、撒娇、哄再乘这个系数，只作用于普通群友 |
| `member_negative_scale` | `0.35` | 群友的**负向**强度（0.05–1.5）：单个群友的硬话从 40 心结只到 54（仍是委屈），再一句就可能进生气；想进害怕要更重，就调大 |
| `owner_negative_scale` | `0.5` | 鱼主的**负向**强度（0.05–1.5）：默认是私聊的一半，但仍比群友重——单个硬话 40 → 60（生气），不会直接回避，连续三次才会 |
| `dm_ratio` | `0.0` | **群友模式下主动私聊鱼主的比例**（0–1）。0 = 只发群（旧行为）；0.3 = 三成主动消息改发私聊；1 = 全发私聊。找不到私聊会话就回落到群里，绝不发给群友；私聊发失败也会自动改发群 |
| `dm_umo` | 空 | **群友模式下私聊他的会话**（可选）。留空自动找：他最近一次私聊用的会话 → 群平台 + `owner_ids` 里唯一的 QQ。填群会话会被忽略 |

**鱼主差分**：`owner_ids` 填了鱼主的 QQ 时，他仍按 `owner_scale`（默认 1.0，不打折）和 `owner_negative_scale`（默认 0.5）算，普通群友才吃 0.5 / 0.35 的折扣；`owner_ids` 为空时认不出鱼主，所有人都按群友算。

**生气按人拆**：谁是这次生气的来源，谁就是生气对象（`anger_targets`，12 小时有效，可同时有多个）；A 惹了她，B 再说话时看到的是**委屈**，只有 A 会看到**生气**。B 的安慰/道歉不能替 A 消气；A、B 都是对象时，B 道歉只解除 B，最后一个对象道歉后才真正降全局责怪；害怕/回避仍按全局压力走。

**负面情绪分源递减**：鱼主和群友各算一个热度桶——群友**不论是谁、说的是哪一档**，共用一个桶；同一桶 10 分钟内第 n+1 次负面情绪，责怪和该事件的负面驱动按 `1 / (1 + n/12)` 缩水。鱼主刷屏不会稀释群友的第一次责怪，群友刷屏也不会稀释鱼主；私聊 / 非群友模式仍按原来的算法（责怪不递减）。

**怎么用**：把 `group_mode.enabled` 打开（**对所有群生效**），`member_scale` 按需要调（默认 0.5，越小越难影响她），负向单独由 `member_negative_scale`（群友，默认 0.35）和 `owner_negative_scale`（鱼主，默认 0.5）控制；想让鱼主保持私聊强度，就把他的 QQ 填进 `owner_ids`（`owner_scale` 默认 1.0）。再把 `proactive.target_umo` 填成那个群的 UMO（在群里发 `/心 umo` 可查）。**群友模式下她默认只往群里主动开口，不会私聊**；想让她也能给鱼主发私信，把 `dm_ratio` 调大（0.3 = 三成主动消息走私聊，1 = 全走私聊），私聊地址留空会自动找，也可以用 `dm_umo` 指定。如果还没收到过任何群消息，她会先不发。群里主动说话时会带上带发言人的最近流水，让她自己判断是在对一个人说（用「你」）还是对几个人说（用「你们」）；走私聊时按私聊口径说话。

> **旧配置自动迁移**：0.3.9 起这几项从 `perception` / `proactive` 挪到了顶层的 `group_mode` 段。旧的 `perception.group_everyone`、`perception.group_scale`、`perception.group_owner_scale`、`perception.group_negative_scale`、`perception.group_owner_negative_scale`、`proactive.group_dm_ratio`、`proactive.dm_umo` 第一次启动会自动并进新段并写回配置（只做一次；新段里已有的值不会被旧键覆盖），没迁移成功时旧键照常生效。

### 回避档 `shut`

只在她进入「回避」档（责怪 ≥ 80）时生效。详见前文「回避档的已读不回」。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 允许她已读不回。关掉后她进回避档也照常回话，只是语气冷 |

回不回的阶梯写死在 `SHUT_REPLY_LADDER`（`main.py` 顶部）：前 5 条 0% → 第 6 条 50% → 第 7 条起 100%。
群聊另有 `SHUT_GROUP_GRACE = 1`（刚进回避时多放行一句）。必回的例外（写死，不可配）：命令、真哄 / 道歉 / 说清楚。

### 渠道权重 `channel`

同一句话，在私聊和群里的分量不同。

| 键 | 默认 | 说明 |
|---|---|---|
| `group_base_weight` | `0.35` | 群里说话的基础权重（私聊固定 1.0） |
| `negative_multiplier` | `1.2` | **非群友模式**的群聊里，负向事件（被凶/被敷衍）的倍率；群友模式改用 `group_mode.member_negative_scale`（群友）/ `group_mode.owner_negative_scale`（鱼主） |

实际权重 = `group_base_weight × 时长因子`：

| 距上次私聊 | 因子 | 最终权重 | 一句"谢谢"给亲密度 |
|---|---|---|---|
| 私聊 | — | 1.0 | +4.0 |
| < 6 小时 | 1.0 | 0.35 | +1.4 |
| < 24 小时 | 0.7 | 0.245 | +0.98 |
| < 72 小时 | 0.45 | 0.1575 | +0.63 |
| ≥ 72 小时 | 0.25 | 0.0875 | +0.35 |

还有一道**群聊天花板**：`intimacy` 上限 70、`attachment` 上限 80。它只限制"往上涨"，不会把已经更高的值压下来——所以私聊攒下的深度不会被群聊抹平，但群聊也推不上去。

负向事件在**非群友模式**的群里不打折：按 `×1.2` 计，比私聊更难受；群友模式下另按 `member_negative_scale`（群友 0.35）/ `owner_negative_scale`（鱼主 0.5）。

### 念头 `thought`

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 是否生成新念头（关掉后已有的照常过期，心境与主动说话不受影响） |
| `spawn_chance` | `0.25` | 每次心跳生成念头的概率（心跳默认 45 分钟一次） |
| `min_weight` | `0.2` | 入池门槛：触发强度低于它的念头不生成。强度只有 0.8 / 0.9 / 1.0 / 1.1 / 1.2 五档，所以 0.2 等于不过滤，1.3 以上等于关闭 |
| `proactive_push` | `0.15` | 有念头时主动说话的概率加成，**加法**：基础 15% 会变成 30%（与沉默加成叠加，上限 85%） |
| `settle_cooldown_minutes` | `10` | 两条念头完成的冷却：一次只完成一条，完成后再等这么久；`0` 取消冷却 |

念头的存活时长按类型固定（1.2–4 小时），不可配置。

念头还会影响她**要不要开口**——不是一律加成，而是分方向的：

| 念头 | 对开口概率的影响 |
|---|---|
| 想他 / 抱抱 / 想讲 / 问他 / 夸夸 | 全额加成（`+proactive_push`） |
| 等回话 | 加成减半（忍不住想催，但别太猛） |
| 想做事 | 不加不减（跟说不说话没关系） |
| 安静 | **反向扣**（本来就想安静，不该更想开口） |

### 隐藏的欲 `desire`

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 启用隐藏的欲；`/心 status` 不显示数值，WebUI 解锁后由「隐藏的欲」卡片显示 |
| `bond_threshold` | `80` | 依恋、亲密都达到这个值才算关系满格（和面板满格线一致） |
| `unlock_hold_hours` | `24` | 两条都满格并持续这么久，才解锁欲 |
| `lock_below` | `75` | 解锁后任意一条掉到这个值以下，欲快速回落并锁回 |
| `adult_enabled` | `false` | 成人向身体层总开关，默认关 |
| `adult_consent_hours` | `24` | `/adult on` 的有效期；`0` = 直到 `/adult off` |
| `scene_consent_minutes` | `60` | 对话里明确说“可以/想继续”等，当前场景同意的有效期 |
| `consent_window_minutes` | `10` | 她刚问过“想继续吗/可以继续吗”后，“嗯/好/行/可以”才算同意的窗口 |
| `inject_interval_minutes` | `5` | 正常聊天里欲的主动提示最多多久注入一次；`0` = 每轮注入 |
| `peak_hold_hours` | `6` | 欲刚到 100 后的收益减半时长；`0` = 关闭饱和期 |

> 面板只显示「启用隐藏的欲」和「允许成人向身体层」两个开关；阈值、持续时长、同意有效期、弱肯定窗口、主动提示间隔、峰值饱和时长等高级项默认隐藏，需要直接改配置 JSON。这样面板不会被一堆数值占满。

- 欲只在**私聊鱼主**生效；群聊、陌生人、睡着、生气、害怕、回避时不会走身体层
- 关系没双满时欲始终是 0；双满 24 小时后从 10–20 开始，慢慢涨落
- 欲 ≥30 后，**正常聊天默认每 5 分钟最多一次**追加一小段“主动一点”的定性提示（不走心境节流）；主动消息每次注入主动版；不显示数值。睡着、压力 ≥50、疲惫 ≥65 时不注入
- 成人场景里他明确说“想要你/想亲你/想抱你”等，欲 **+3**，并记入「最近涨落」；普通“抱抱”仍按安抚/释放处理（当前 -4），不叠加成人互动
- 成人层允许时，欲的注入会更直接：`想要他 / 想被他抱 / 想贴着他 / 想让他碰 / 想被他摸 / 想被他压着 / 想要他更近`；未允许时最多到“想被抱、想独处”，并明确“别往身体层走”。注入只写意图，不写具体性行为细节；停止仍由成人同意状态机处理，不再在注入里写“他说停就停”
- **自然收尾**：当前场景里说“先这样 / 抱一会儿就好 / 抱抱就好 / 今天就到这里 / 睡觉吧 / 晚安 / 休息吧 / 够了 / 不继续了”等，会关闭当前场景并显示“成人层：收尾”，不算喊停；长期 `/adult on` 保留，下次说“想要”或 `/adult on` 恢复。纯 `/adult on`、没有当前场景时，只要成人层此刻可用（欲 ≥60、关系满格、日常、无高压力/高疲惫），“晚安”也会收尾；条件不满足则不会暂停长期预授权
- 软收尾会排除否定和问句：`我不困了 / 不够了 / 睡了吗 / 晚安吗 / 不休息吧` 不会误触发；暂停/收尾的边界注入不受 5 分钟限频影响，状态变化会立即告诉模型
- 欲刚到 100 时开始 6 小时饱和期：期间所有正向涨欲收益减半；之后恢复正常
- **欲已解锁的私聊里**，轻/中/重责只扣欲（-3/-6/-10），不增加责怪、压力、喜悦、依恋、反刍；中/重责另外暂停成人层，重责清掉当前场景同意，长期 `/adult on` 保留；已有的责怪不会被这条规则清零
- 中/重责后即使责怪档仍是日常，**成人层也会暂停**；如果她本来就在委屈/生气/害怕/回避，成人层同样不可用，主动欲提示不出现，欲按心跳退潮
- 重责本身会扣欲（`blame_hard -10`），但不是立刻归零；残留的欲只作为内部状态，不会绕过成人层暂停
- 依恋/亲密掉出 80 但还在 75 以上：不再加欲，按心跳额外回落（0.40/跳），成人层和主动欲提示同时停；任意一条 <75 立即锁回 0
- **WebUI**：解锁后多一张独立的「隐藏的欲」卡片（横跨整行，放在六张卡之后），显示当前值、阶段、成人层状态和最近 5 条涨落；未解锁时整张卡隐藏，不挤占原有卡片
- 身体层要同时满足：`adult_enabled` + 私聊鱼主 + 欲已解锁且 ≥60 + 长期/场景同意 + 未暂停
- `/adult on|off|status` 管长期同意；`/adult on` 只是预授权，不是必需——当前场景明确同意也能进；`/adult` 只在私聊、只认 `perception.owner_ids` 里的鱼主
- 自然语言同意分两类：`我想要你 / 我要你 / 想亲你 / 想吻你 / 不要停 / 别停 / 不想停 / 不可以停 / 不能停` 可直接给场景；`可以继续 / 想继续 / 继续刚才 / 继续吧` 和 `抱我 / 亲我` 一样，必须她刚问过或场景已经建立；**单独的“继续”不算**；`抱抱可以吗` 不会打开弱肯定窗口
- “不要/停/不可以/不行/不能继续/不舒服/不想”立即暂停；“不要紧/不用/没事”不算暂停；“不要停/别停/不想停/不可以停/不能停”按最长短语优先，算肯定；`快停/赶紧停/马上停/立刻停` 也认
- 欲高不等于同意；同意也不等于她现在就想要。她可以拒绝、可以只要抱抱
- `diagnostics.log_affect` 的 before/after 和 `applied_total` 会带 `desire`；`/心 status` 不显示数值，WebUI 解锁后由「隐藏的欲」卡片显示

### 调试

| 键 | 默认 | 说明 |
|---|---|---|
| `debug` | `false` | 打开后每次心跳/注入/主动说话都写一条日志 |
| `diagnostics.log_affect` | `false` | **全量影响日志**：每条对话写一行 `[鱼的心][影响] {...}` JSON，含原文、渠道、发言人、识别事件、实际增量、前后九维/责怪/期待/档位/心情。负向消息会带 `"negative": true`。含聊天原文，注意隐私；默认关闭 |

影响日志是**一条消息一行 JSON**，方便直接 `grep`、导出或做对比。没触发事件的普通闲聊也会记（`events: []`）；群友模式下不在白名单的群友消息、以及 `outsider_effect=none` 被忽略的消息也会记，并带 `ignored` 字段，方便查“为什么这句话没影响她”。

## 4. 命令

```
/心                查看当前心境（心情 + 责怪档 + 九维条 + 念头 + 上次主动说话）
/心 status         同上（含"最近责怪"、下次褪值、心结说明）
/心 calm           只把责怪/心结清零，回到日常；九维不动
/心 reset          重置为初始状态（只清情绪数据，不动记忆）
/心 tick           手动跳一次心跳（调试用）
/心 off / on       本次运行内开关（重启后以配置为准）
/心 umo            查看当前会话 UMO（填配置用）
/adult on          同意成人向身体层（私聊鱼主；默认 24h）
/adult off         撤销成人向同意
/adult status      查看成人向开关、同意剩余时间、关系门槛
```

> **成人向**：`/adult` 只认私聊里的严格鱼主；`adult_enabled` 是总开关，`/adult on` 是私聊同意，自然语言里的明确“可以/想继续”只给当前场景。欲高不等于同意，同意也不等于她现在想要。
>
> **状态显示**：第一行是 `心情：黏人/开心/累了/紧绷/走神/好奇/平常`，第二行是 `责怪档：日常/委屈/生气/害怕/回避｜责怪 x/100`。`日常` 只表示“没在生气”，不是“没有情绪”；心情由九维决定，夸/撒娇/及时回会改心情，不会改责怪档。
>
> `/心 status` 的「最近责怪」只显示**当前会话渠道**：群里不会贴最近私聊的原话，私聊也不会贴群聊的原话。`/心 tick` 附带的 status 同样按当前渠道过滤。
>
> **群聊权限**：`/心` 只允许 `perception.owner_ids` 里的鱼主使用（`/心 umo` 除外，它只回当前群 UMO，不含心境）。打开 `group_mode.enabled` 也不会放开命令权限；非鱼主在群里发其他子命令会被**静默忽略，不回复权限提示**。没配 `owner_ids` 时，群里只能查 UMO。

插件自带一个面板页面，在 AstrBot 插件详情页点「页面」即可打开（4.25.3 起侧边栏「扩展功能」里也有入口）。

页面在仓库里有两份、内容完全一致：`views/heart/`（4.29+ 用）和 `pages/heart/`（4.24.2–4.28 用）。改页面时只需要改 `views/heart/`，然后跑一次：

```bash

python tools/sync_pages.py --check  # 发版前检查两份是否漂移（不一致退出码 1）
```

**4.24.2–4.25.2 的用户看不到侧边栏入口是正常的**，那个区间只能从插件详情页的「页面 → 打开页面」进。

顶部是插画图带和两个徽章，下面 3×2 六张等大卡片；欲解锁后会在六张卡之后多一张横跨整行的「隐藏的欲」卡片：

- 右边第一个徽章是**心情**（黏人 / 想亲近 / 开心 / 累了 / 紧绷 / 走神 / 好奇 / 日常）——由九维当下推导，颜色仍按责怪档走；这是她现在“看起来什么样”的主标签
- 第二个是**责怪档**（日常 / 委屈 / 生气 / 害怕 / 回避）——只看责怪压力，决定她怎么说话。`日常` 表示“没在生气”，不是没有情绪；**日常时第二枚徽章会隐藏，避免“黏人 · 没在生气”重复**，委屈/生气/害怕/回避才显示；责怪卡在 40 时会写成**委屈·旧账**（悬停有说明）；生气时会写成**生气·对某某**，只对那个人冷

- **九维驱动**——当前九个维度相对基线的位置
- **此刻**——依恋 / 亲密 / 期待 / 责怪四个环，压力 / 喜悦 / 社交 / 疲惫 / 好奇 / 反刍 / 责任七条细条，以及一句**短描述**（只写她此刻什么样，不摆注入用的指令）；责怪那一行还会写清**下次褪值时间**，或者"心结：不哄不会掉"，并附上**最近一次责怪的时间、渠道、谁说的和原句**
- **隐藏的欲**——只在解锁后出现，横跨整行放在六张卡之后：当前值 / 阶段 / 成人层状态 / 最近 5 条涨落；未解锁时整张卡隐藏，不占位
- **念头**——可滚动，只列还没被满足的念头，每条带 TTL 进度和「满足条件」；页面最顶部的卡片放**最近完成**（回味中）、**自己缓过来**（自愈，2 小时内最多 5 条逐条列出）、**最近放下**（主动开口三次没被接住），超过 2 小时自动隐藏；下方还有「**最近的变化**」，逐条列出刚才是哪件事让哪个维度涨了多少
- **主动说话**——今日次数、冷却剩余、上次开口、是否在等你回、当前配置（含念头的入池门槛与开口加成），以及一句**「她现在为什么安静」**（总开关关 / 主动说话关 / 每日 0 次 / 她在回避 / 她在生气 / 睡着了 / 今日已满 / 随时可能开口）；普通冷却中这句不显示——上面「冷却剩余」那块已经在倒计时，不重复说
- **最近说过的话**——优先读 AstrBot 的真实对话历史（双方都在），拿不到时回退插件自身的 recent；显示时过滤 `&&soft&&` 这类语气标记和 `[图片]` 占位
- **心境报到簿**——哪些会话已经看到过当前心境

「刷新」重新拉取；「替她跳一次心跳」等价于在聊天里发 `/心 tick`——**两者都会真的掷一次骰子**，成功提示"她刚开口了"，没中提示"概率未命中"。

页面跟随 AstrBot 的明暗主题，数据每 60 秒自动刷新。

**归一化显示**：九维的圆环和进度条都是 0–100，但依恋 / 亲密实际到不了 100，
所以这两个按 `DIM_DISPLAY_MAX`（默认 80）映射后再显示——真实 72 显示 90、真实 80 显示 100。
数字和填充比例用同一个基准，不会出现"数字 72、圈却是满的"。
鼠标悬停任意一项能看到真实值；`/心 status` 里仍然是真实值。

依恋 / 亲密两个环上还有一道**里程碑刻度线**，标在「黏人」门槛（66 → 82%）：
满格是 80，刻度线是"到这儿才算黏人"。所以黏人亮起来时环只填了 82%，
后面还有成长空间；两条都到 80 并持续 24 小时，会解锁隐藏的「欲」。

## 7. 已知限制

1. **一颗心，一套状态**。九维是全局单例，不按会话分开。服务多个人时，"对谁有依恋"会说不清——建议只服务一个主要对象。
2. **主动说话不走事件管线**。它直接用 `Context.send_message` 出站，所以不会触发其他插件的 `on_llm_response`（TTS、表情、内容过滤都看不到这条消息）；但它会**回写 AstrBot 的对话历史**，所以下一轮聊天她记得。
3. **感知主要靠关键词，不是语义**。责怪、哄、夸奖、撒娇都是按词表匹配的，偶尔会误判。可选打开 `perception.blame_judge`：只对“有责怪词、但规则没判出”的模糊句额外问一次 LLM；默认关闭，失败/超时回退规则，成人同意不参与。夸奖分两档：**明确夸奖**（"你真棒""好厉害""优秀""谢谢"）满额，**含蓄夸奖**（"你真是我的小棉袄""你真贴心""真乖"）按约 55% 结算、事件记为「含蓄夸奖」，可用 `perception.praise_soft` 关掉（关掉后退回只认明确夸奖词，"乖"仍按哄算）。含蓄夸奖有三道过滤：**否定不算**（"你不乖"）、**说别人不算**（"我女儿真是我的小棉袄"）、**反问不算**（"你贴心吗"），"乖，别闹了"这类哄人的话也不算夸。**夸多了会腻**（`perception.praise_fatigue`，默认开）：同一个人在 30 分钟内夸到第 3 次降成「夸奖（听腻了）」，第 5 次起「夸奖（夸过头了）」（喜悦 −1、压力 +2），同时给她注入"你听腻了"的提示，让她半开玩笑地拆穿他或把话题拉回具体的事；不会加责怪、不扣依恋，按说话人分桶，`抱抱/想你/辛苦了` 这类由哄映射出来的夸奖不计入。词表里**刻意不收高频词**：「累」「怕」「抱」都不算撒娇（说句"今天上班好累"只是普通说话），而且撒娇只认**在说自己的情绪**——"我委屈""我今天好难受"算，"你是不是委屈了""你委屈吗"是关心她，不算（否则问一句就白涨依恋，还会把"想他"的念头喂饱）。「我在」不再算哄（"我在开会"），「好久」从夸奖里删了（"好久不见"不是夸她），「真好」也从裸词表里拿掉（"真好吃""真好玩"不是夸她，只有"你真好"这类指向她的才算），「不行」「不对」不再算轻责（"今天不行，改天吧"、"不对，我记错了"都不是在说她），「你怎么看」「你怎么了」这类提问/关心也排除在外，「随便你点什么都行」不再算敷衍。责怪还有三道过滤：**否定式先抹掉**（"我不讨厌你""不是说你"）、**描述性词要求句中出现"你"**（"这电影真恶心"不算，"你真恶心"才算）、**"滚"只认单独使用**（"滚""滚吧""滚开"算，"滚烫""滚动""滚去睡""水滚了"不算）。**昵称先豁免**："小笨蛋""小笨鱼""笨鱼"这类称呼不算责怪，昵称句里的"你怎么这么笨"也按打趣处理；"笨"只认"你真笨""笨死了""笨猪""你笨"这种明确骂法，硬词（"滚""没用""烦死了"）仍照记。剩下的仍是字面匹配：反讽、玩笑、以及"你很烦"这种半真半假的抱怨，都可能被当真。
4. **连续两次主动开口**会在对话历史里产生相邻的 assistant 轮。OpenAI 兼容协议没问题，严格 user/assistant 交替的协议可能报错。
5. **群聊合并消息时**，"这句话是谁说的"可能只反映最后一个人。
6. **被无视的那几句不进 AstrBot 的对话历史**。她沉默时是直接终止事件（不请求 LLM），AstrBot 因此不会落盘这条 user 消息。插件会把这几个句子单独补进下一次的心境注入里，但在其它插件看来那几句话是不存在的。
7. **阶梯是写死的**。前 5 条必不回、第 6 条 50%、第 7 条必回，不开放配置（只在 `shut.enabled` 上留了总闸）。要改就改 `SHUT_REPLY_LADDER` 那一行，长度就是保留条数。
8. **群聊桥的是"前因"，不是完整上下文**。她能看到触发句 + 前 3 条（他 / 你 / 群友），够对上"因为什么"，但更早的来龙去脉没有。真要完整因果，还是得口头讲——而你私聊前 5 条她不回（但会记进 `unanswered`，第 6/7 条一起给她）。
9. **群友的态度不影响她的心**（默认）。白名单之外的人在群里安慰她、@ 她、凶她，都只算"热闹"——社交 / 喜悦**最多** +2 / +1，而且和别的一样受"越接近 100 加得越少"和批次退热的限制，几十条消息也顶不满。碰不到责怪与压力。`owner_ids` 与 `target_umo` 全空时：私聊仍放行（否则取不到 ID 她就彻底失灵），**群聊一律按外人处理**——这一条是 0.3.3 改的，之前群里谁说话都算"他"。**例外**：`group_mode.enabled: true` 时全群都能影响她（强度乘 `group_mode.member_scale`），这是给"她主要活在群里"的部署准备的。
10. **100 分只是个渐近线**。增益按 `1 - 当前值/天花板` 缩放、天花板默认 100，所以越接近 100 越慢，永远差最后一点点；再叠上回落，三天满勤大概到 75–83。这是刻意的养成难度，不是 bug。
11. **反刍的"走神"线（65）基本到不了**。反刍只靠 `silent_6h` 的 +3（还会被天花板/退热打折）顶着每心跳 3% 的回落，30 天模拟里均衡在 51–61。所以「走神」这个心情很少出现；`deep` 的反刍门槛因此定在 **55**。

## 8. 常见问题

**为什么她一直显示「日常」？**
`日常` 只是“责怪 <25、没在生气”，不是“没有情绪”。她可能同时是黏人、开心、累了、紧绷、走神或好奇，这些看第一枚心情徽章。正向聊天会改心情，不会改责怪档；只有被凶、被敷衍、被比较等负向事件才会把责怪档推到委屈/生气/害怕/回避。

**隐藏的「欲」什么时候出现？**
依恋、亲密都到 80 并持续 24 小时才解锁；`/心 status` 不显示数值，WebUI 解锁后由「隐藏的欲」卡片显示。它只在私聊鱼主生效，群聊/陌生人/睡着/生气/回避时不表达。成人向身体层还要 `desire.adult_enabled` + 私聊鱼主 + 当前场景的明确同意；`/adult on` 只是 24 小时预授权，不是必需。`/adult status` 只看同意和关系门槛，不看欲的数字。

**她为什么不主动说话？**
按顺序查这六道闸：总开关 → `proactive.enabled` → 睡着（作息）→ 冷却（默认 6 小时）→ 每日上限 → 沉默时间（默认 10 分钟）；此外还要过"当前档位不是回避"，以及一次概率掷骰。

概率不是固定的：基础值由九维算出（约 5%–65%），心里有未满足的念头会 ×1.3，**沉默越久越往上加**（12 小时起线性加成，最多 ×2.5，总上限 85%）。

`/心 tick` 或面板上的「替她跳一次心跳」可以立刻掷一次，并直接告诉你她开没开口；`/心 status` 看她上次开口是什么时候。

如果日志出现 `不合法的 session 字符串：not enough values to unpack (expected 3, got 1)`，是「主动说话 → 目标会话」填成了裸 QQ 号、群号或半截 UMO。这里必须是 **`platform:MessageType:session_id`** 三段（例如 `aiocqhttp:FriendMessage:123456` 或 `aiocqhttp:GroupMessage:123456`）。在目标会话里发 `/心 umo` 可复制完整值；0.3.7 起格式不对会提前跳过并写清原因，不再把裸 ID 丢给 `send_message`。

**她怎么不回我？**
先发 `/心 status` 看是不是**回避**档。回避档下前 5 条她一条都不回，第 6 条一半几率，第 7 条一定回。
不是这个原因的话，检查：`/心` 命令能不能用（能用说明插件活着）、AstrBot 日志里有没有"终止了事件传播"、`debug: true` 后有没有 `回避档：这条选择不回` 那行。
想关掉：`shut.enabled` 设 `false`。

**她为什么突然"懂"了我的状态？**
因为她真的收到了。回避档下被你无视的那几句不会进 AstrBot 的历史，所以插件在下次注入时补一句「你刚才没回的话」——她记得你说过什么，只是当时没理。

**群里别人安慰她、@ 她，有用吗？**
没用。白名单之外的人只能让气氛热闹（社交 +2、喜悦 +1），碰不到责怪与压力，也解不了回避。想把她哄回来只能你自己来，而且**私聊比群里快**：私聊一轮真哄扣 18 点责怪（回避档），群里一轮只扣 `18 × 0.35 ≈ 6.3`（还随"距上次私聊多久"继续降）。群里哄两轮 ≈ 私聊哄一轮。生气档另算：只认道歉/说清楚，普通抱抱不算进度。

**群里哄和私聊哄，判定一样吗？**
判定一样（真哄要连够轮数、敷衍会作废、进度跨渠道共用），**力度不一样**——就是上面那个渠道权重的差别。生气档另有一条：只认道歉 / 说清楚，普通哄抱不算进度。

**她会自己好吗？**
会，但慢。没人哄时责怪压力每 6 小时掉 8 点，**止于 40（心结）**。从 96 点算：约 18 小时后掉到 72（离开回避档，开始回你话），约 42 小时后停在 40（委屈档），不会自己回到日常。这段时间里她不主动开口，也不回你——除非你哄/道歉/说清楚（必回）或发命令。到了 40 就是"旧账"，面板会写**委屈·旧账**；不想等就 `/心 calm`（只清责怪，九维不动）或真哄。

**面板显示她委屈，可她说自己没委屈，也找不到是谁凶了她？**
先看 `/心 status` 的「最近责怪」——0.3.3 起会记下时间、渠道和原句，0.3.6 起还会写**是谁说的**（群里·鱼主 / 群里·昵称），面板"此刻"里也有。四种常见情况：① 责怪只是被某句话的关键词触发了，不是真在骂她（"今天烦死了""滚去睡""这个没用"这类在 0.3.3 已经不算了）；② 责怪早就褪到 40 的心结，触发句是很久以前的事；③ 白名单没配、群聊被当成了"他"（0.3.3 起群聊默认按外人处理）；④ 昵称/比较句里的「笨」被误判（「小笨鱼你在干嘛」0.3.5 起不算、「比你还笨」0.3.6 起不算）。如果状态头写「责怪 60/100 = 心结 40 + 另 20」，那 20 才是这次新加的，40 是之前留下来的心结底；她"说没委屈"则是因为心境块只写状态、不写缘由，现在会把原句一起给她；你直接问"你是不是委屈了"时也会强制注入一次。

**她为什么像在编没发生过的事？**
0.3.3 起有三道防线：主动消息只引用真实对话、念头不被说成回忆、心境注入写明"不要编造没发生的对话/约定"。0.3.7 起主动消息会读带 `[月-日 时:分]` 的时间线（私聊 `recent` 留 60 条、读取 40 条），并在发送前检查草稿有没有声称记录里没有的近况。但 fish_heart **不存记忆**——它只有这条私聊时间线和 AstrBot 的对话历史。如果历史很短或没装记忆插件，她能引用的东西就很少，剩下仍靠人设与模型发挥；要真的"记得住"，请配记忆插件。

**她在群里不认我？**
检查 `perception.owner_ids`。留空时会从 `target_umo` 末段自动反推——但如果 `target_umo` 填的是群 UMO，推导会被跳过（群号不是人）。

**她说话怎么不分条？**
这句话里没有句末标点（切不出多段就原样发一条）；分段发送已固定开启，不再提供开关。

**群里她对我说话怎么没反应？**
这是设计：群里同一句话的分量按"距上次私聊多久"打折，3 天没私聊的话，群里说一句约等于私聊的 1/11。想恢复深度，去私聊。

**面板打不开 / 显示读不到她的状态？**
先确认 AstrBot 版本 ≥ 4.24.2（4.24.2 以下没有插件页面能力，装上也点不开），再确认插件已重载（页面接口在 initialize 里注册）。4.24.2–4.25.2 只有插件详情页里的「页面 → 打开页面」，侧边栏没有入口是正常的。
如果 4.29+ 仍然看不到，打开 `http://<你的地址>:6185/api/plugin/detail?name=astrbot_plugin_fish_heart` 看返回 JSON 里的 `pages` 字段：有 `heart` 说明插件侧正常，是入口位置问题；为空则多半是插件没启用/没加载成功，或装的还是只有 `views/` 的旧包。
**改完配置要重启吗？**
改 `state` 相关不用；改插件代码或 `_conf_schema.json` 需要重载插件。
